# Personal Portfolio Template

This is a simple, single-page personal portfolio website template. It's built with HTML and CSS.

## Key Files

*   `index.html`: The main HTML file containing the structure of the portfolio.
*   `style.css`: The CSS file for styling the portfolio.

## How to Use

1.  Clone or download this repository.
2.  Edit `index.html` to add your personal information, projects, and links.
3.  Customize `style.css` to change the appearance if desired.
4.  Replace the placeholder image `https://placekitten.com/150/150` in `index.html` with your own photo.

This project is based on a simple template and is intended for easy customization.
